當使用排程工作（Task Scheduler）或 win-acme 自動化工具以 SYSTEM 身分執行憑證更新與指令碼時，必須具備此權限。

1.開啟本機安全性原則：Windows 系統工具。按下鍵盤快捷鍵 Win + R 開啟「執行」視窗。輸入 secpol.msc 並點擊「確定」（或按 Enter）。

2.在左側樹狀目錄依序展開：安全性設定 -> 本機原則 (Local Policies) -> 使用者權利指派 (User Rights Assignment)。
  在右側清單中找到 「以批次作業方式登入 (Log on as a batch job)」（對應常數即為 SeBatchLogonRight），對其按滑鼠右鍵選擇「內容」（或按兩下開啟）。

3.點擊右側的 「位置(L)...」 按鈕。在彈出的樹狀清單中，將選取目標從網域往上改選為這台伺服器本機電腦名稱（最上方圖示為單台電腦）。
  點擊 「新增使用者或群組(U)...」。在「輸入物件名稱來選取」框中輸入：SYSTEM
  點擊右側的 「檢查名稱(C)」，系統會自動轉換為底線格式（例如 SYSTEM 或 NT AUTHORITY\SYSTEM）。
  依序點擊 「確定」 -> 「套用」 -> 「確定」 關閉所有視窗。驗證方式：重新開啟該原則內容，清單中可見 SYSTEM 出現在使用者名單中。

4.立即套用原則更新：為避免等待 Windows 週期性重新整理原則，開啟以系統管理員身分執行的 CMD 並輸入：gpupdate /force


驗證方式：命令提示字元顯示「使用者原則更新已成功完成」與「電腦原則更新已成功完成」。若「新增使用者或群組」按鈕呈現灰色（反灰無法點擊）：代表此伺服器已加入 Active Directory 網域，且該權限是由網域控制站的 群組原則 (GPO) 統一控管。此時必須聯絡網域管理員，至網域的 Group Policy Management（GPMC）中將 NT AUTHORITY\SYSTEM 加入該 GPO 的「以批次作業方式登入」原則中。
